# MusicNote Haven MIDI Manager

**MusicNote Haven MIDI Manager** is a desktop application in active development for musicians, keyboard players, MIDI collectors and digital music archivists.

It is designed for people who work with large `.mid`, `.midi` and `.kar` collections and want a safer, clearer way to index, search, organize, review and play their files.

## Official website

Visit the official MusicNote Haven website:

**https://musicnotehaven.ethercomm.eu**

The website includes current public product information and an early public manual.

## What MIDI Manager is being built for

MIDI Manager is focused on practical workflows for large MIDI and karaoke file archives:

- index large MIDI/KAR collections
- search and browse archived files
- review unknown or unsorted files
- organize files into a cleaner Organized Library
- play and check MIDI/KAR files
- mark liked/favorite files
- use a playback queue for advanced listening workflows
- keep original source archives safe
- use verified copy workflows
- support Trial/Free, Personal and Professional license tiers
