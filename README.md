# MusicNote Haven MIDI Manager

**MusicNote Haven MIDI Manager 1.1.0** is local desktop software for musicians, keyboard players, MIDI collectors and digital music archivists who manage `.mid`, `.midi` and `.kar` collections.

## 1.1.0 highlights

- Professional sidebar/navigation and refreshed Dark/Light MIDI Manager branding.
- Clearer Dashboard, semantic status colors and delayed wait feedback.
- Explicit Search/Enter behavior, accent/diacritic-tolerant search foundations and stronger large-result handling.
- Recognition identity provenance, existing-library re-evaluation and targeted reanalysis without a new profile/database.
- First-class local lyrics from embedded/local/manual sources plus a provider-neutral explicit lookup/review/save route.
- Incremental database-backed Organized Library browsing, advanced filters and compact File Detail actions.
- Copy-first Organizer planning, review, execution/verification, safer progress/cancellation and recovery foundations.
- Settings, Licensing and Library Health with preview-first hygiene/planning workflows.
- Centralized playback ownership, wrapped tooltips, adaptive command rows and exact context-help/manual deep links.
- Floppy Image Studio: Create Image plus Single IMG, Folder Catalog and Reports.
- English, Dutch, German, French and Spanish runtime localization.

Not bundled in 1.1.0: the planned local replaceable MusicBrainz reference cache and provider-specific commercial lyrics integration.

## Safety and privacy

MIDI Manager runs locally and does not upload the user's MIDI/KAR collection. Public packages exclude private administration material, local databases, private configuration, SoundFonts and MIDI/KAR collections. Independent backups remain recommended before major archive operations.
