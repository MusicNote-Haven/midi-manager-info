# MusicNote Haven MIDI Manager

## Current 1.2-family highlights

- Durable Source Index and resumable Technical MIDI Scan.
- Recognition 2.0 with inspectable evidence, provenance, Re-evaluate Library and Human Review.
- Manual Artist/Title/Filename correction with safe path reconciliation.
- Incremental copy-first Organizer with review-before-apply and verified execution.
- Database-backed Organized Library browsing, search, filters and genre handling.
- MIDI Player and Playback Queue.
- Library Health, exact-identical-file detection and guarded maintenance/archive workflows.
- Floppy Image Studio and IMG Viewer for FAT12/older keyboard/Gotek-oriented workflows.
- Local/embedded/manual lyrics foundations plus provider-neutral explicit lookup/review/save.
- Trial / Free lifetime verified-output enforcement and Personal/Professional licensing foundations.
- English, Dutch, German, French and Spanish UI/manual coverage.
- Tested with libraries approaching 200,000 MIDI/KAR files.

## Current release note

Windows remains on 1.2.1 while Linux is on 1.2.2. Windows/Linux parity is intentionally deferred until known 1.2.x release-blocking defects are closed and regression-tested.

## Safety and privacy

MIDI Manager runs locally and does not upload the user's MIDI/KAR collection. Public packages exclude private administration material, local databases, private configuration, SoundFonts and MIDI/KAR collections. Independent backups remain recommended before major archive operations.
