## Highlights

- Incremental Source Index refresh for large MIDI/KAR collections.
- Resumable Deep MIDI Analysis with safe stop-and-resume behavior.
- Search, File Detail, Failed Analysis Review and detected-device workflows.
- Copy-first Library Organizer and physical Organized Library.
- Playback Queue and favorite/liked-file workflows.
- Floppy Image Studio with FAT12 image creation, recursive catalogs, sidecar manifests and PDF/CSV/JSON reports.
- Improved startup feedback, packaged splash resources and Windows/Linux packaging reliability.

## Important notes

- The Windows installer is currently unsigned. SmartScreen, Defender or browser reputation warnings may appear.
- A SoundFont is optional and is not bundled.
- Keep independent backups and begin with small test folders.
- Newer private development work is not automatically included in these accepted 0.3.0 artifacts.
